# Arena Futvolei

MVP leve para escola de futvolei, feito em HTML, CSS e JavaScript puro.

## O que ja faz

- Cadastro rapido de alunos
- Controle de planos e mensalidades
- Agenda de aulas
- Presenca por aula
- Dashboard do dia com pendencias
- Dados salvos no `localStorage`

## Como abrir

Abra `index.html` no navegador, ou rode:

```bash
npm install
npm start
```
